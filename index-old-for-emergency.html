Music Presence Media Players

This a list of every media player supported with Music Presence and it's updated every month.

The Media Player might not be detected right away, check the Github Issues first, if there is no Github Issue that corresponds with the problem you are having, go to the Discord Server, somebody will help you there.

If the media player you are using isn't supported by Music Presnce, go the Music Presence icon in the system tray, then go to Help > Submit detected media players. (Note that the media player has to be playing something, and you need a Github account)

For now Music Presence can only detect websites on Linux, soon there will be a browser extension for Windows and Mac.

Some players require plugins/extensions, see them here

The app isn't available in iPhone/Android.
